## 📖 简介 (Introduction)

**LifeQuest** 是一款硬核的目标管理工具，专为那些厌倦了枯燥 To-Do List 的奋斗者设计。

我们不只是记录待办事项，我们将你的备考、工作、锻炼转化为一场**史诗级的 RPG 战役**。在这里，你通过完成现实任务赚取经验（XP）和金币（Gold），提升你的四维属性，并与一个全天候成长的“宿敌”进行竞速。

**v3.0 "觉醒版"** 带来了全新的连击系统、循环任务机制以及更智能的对手。

## 🎮 游戏机制 (Game Mechanics)

### 📊 1. 四维属性雷达 (Attributes Radar)
你不再是苍白的“完成者”，你是拥有属性的英雄。每个任务都可以绑定一种属性：
*   **Perception (感知)**：如听力训练、观察练习。
*   **Insight (洞察)**：如阅读、分析报告。
*   **Logic (逻辑)**：如写代码、数学题、写作。
*   **Charisma (魅力)**：如口语练习、演讲、社交。
> *随着任务完成，你的雷达图会动态扩张，直观展示你的长板与短板。*

### 😈 2. 智能宿敌系统 (Rival System)
这是 LifeQuest 的核心。你有一个名为“宿敌”的影子对手：
*   **全天候成长**：即使你关闭软件，他也在离线挂机升级。
*   **随机进化**：每隔 10 分钟，系统会随机判定宿敌是否“努力”了一把。
*   **难度分级**：从 "摸鱼怪 (0.5x)" 到 "神 (2.0x)"，选择适合你的挑战难度。
*   **竞速压力**：右上角的红色进度条时刻提醒你——**他不睡觉，你敢睡吗？**

### 💰 3. 经济系统与战利品 (Economy & Shop)
自律需要正反馈。
*   **赚取赏金**：完成任务获得金币。
*   **战利品商店**：你自己定义商品的奖励（如：喝奶茶、打游戏 1 小时、买新手办）。
*   **消费**：用辛苦赚来的金币购买这些欲望。这让每一次“玩乐”都变得心安理得。

### 🔄 4. 任务体系 (Quest Board)
*   **任务类型**：支持 **一次性任务** 和 **长期循环任务**。
*   **生效日**：你可以设置循环任务只在“周一、三、五”出现，周末自动休息。
*   **过期惩罚**：今日事今日毕。如果循环任务当天未完成，第二天它会被标记为 **[已过期]** 并计入黑历史，这是你战绩上的污点。
*   **连击火焰 (Streak)**：保持每日活跃，点燃连击火焰！连击天数越高，获得的经验金币加成越多（最高 +50%）。

## 🚀 下载与安装 (Installation)

### 对于所有用户 (All Users)
LifeQuest 现已打包为单文件程序，无需安装 Python。

1. 前往 [Releases 页面](../../releases) 下载最新的 `LifeQuest_V3.1.exe`。
2. 将它放在你喜欢的任何地方（桌面、D盘等）。
3. **直接运行**。

> **注意**：首次运行时，软件会自动在你的系统用户目录下创建存档数据库。

## 💾 数据迁移指南 (Migration Guide)

**如果你是从 v2.0 或更早版本升级的老用户：**

为了保持桌面整洁，v3.1 不再在 EXE 同级目录生成文件。请按以下步骤迁移你的老存档：

1. 下载并运行一次 v3.1 新版，然后关闭它（让系统自动建立新文件夹）。
2. 在键盘上按 `Win + R`，输入 `%APPDATA%\LifeQuest` 并回车。
3. 找到你旧版本文件夹里的 `lifequest.db`（存档）和 `config.json`（配置）。
4. 将旧文件**复制并粘贴**到第 2 步打开的文件夹中，覆盖新文件。
5. 重启软件，你的等级、金币和宿敌就全部回来了！

V4.0新增：

## ☁️ 云端账号模式 (Cloud Mode)

项目现在提供了基于 `FastAPI + JWT` 的账号登录与云端同步骨架，适合从单机版平滑升级到毕设所需的服务端架构。

### 本次更新做了什么

- 新增 FastAPI 后端源码：账号注册/登录（JWT）、玩家/宿敌/任务/商店/配置同步接口
- 客户端新增云端登录窗口：登录云端 / 注册并登录 / 继续单机版
- 新增“先单机后联网”能力：单机模式运行后，仍可在软件内登录云端并选择上传本地存档，继续多端同步；也支持把云端最新存档下载到本机用于离线
- 修复注册 500：密码哈希改为 `pbkdf2_sha256`，避免 bcrypt 在部分环境下触发长度/后端问题

### 1. 启动后端

1. 安装后端依赖：
   `pip install -r backend/requirements.txt`
2. 启动服务：
   `python -m uvicorn backend.main:app --host 127.0.0.1 --port 8000 --reload`

默认会使用本地 `SQLite` 文件 `backend/lifequest_cloud.db` 进行开发测试。部署到服务器时，可以通过环境变量 `DATABASE_URL` 切换到 MySQL，例如：

`mysql+pymysql://root:password@127.0.0.1:3306/lifequest_db`

### 2. 启动客户端

1. 安装客户端依赖：
   `pip install -r requirements.txt`
2. 运行：
   `python main_gui.py`

客户端启动后会先弹出登录窗口：

- 选择 `登录云端`：使用账号连接 FastAPI 服务
- 选择 `注册并登录`：创建新账号并直接进入云端
- 选择 `继续单机版`：保留原本本地 SQLite 模式

### 3. 本地数据迁移

如果你这台电脑已有单机版进度，而云端账号还是空白状态，登录成功后客户端会提示是否一键迁移本地数据。迁移内容包括：

- 玩家等级、金币、四维属性、连击、保护卡
- 宿敌数据
- 任务列表与历史状态
- 奖励商店
- 目标名称、目标日期、属性名称配置

### 4. 局域网双机同步测试（A 开热点，B 连接）

用于验证“同一个账号在两台电脑上看到同一份任务/等级/金币”，确保不是单机版各存各的。

前提：
- 两台电脑在同一局域网：A 电脑开热点，B 电脑连接该热点
- A 电脑 IPv4：`192.168.0.0`（以你的实际为准）

步骤：
1. 在 A 电脑启动后端（必须监听所有网卡）：
   `python -m uvicorn backend.main:app --host 0.0.0.0 --port 8000 --reload`
2. 在 B 电脑打开客户端登录窗口，服务器地址填写：
   `http://192.168.0.0:8000`
3. 两台电脑用同一个账号登录
4. 在 A 电脑创建一个明显的测试任务（如 `跨设备同步测试-20260730`），B 电脑刷新/重启后能看到即代表同步成功

提示：
- 如果 B 电脑填 `http://127.0.0.1:8000`，它连的是 B 自己电脑的本地地址，不是 A 的后端
